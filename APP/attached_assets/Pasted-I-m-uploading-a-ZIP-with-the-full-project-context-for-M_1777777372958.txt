Project name: Mapazapp.
Previous working name: QuerlyTrader Guard. Use Mapazapp everywhere in the UI, code, README and docs.

Important architecture:
Mapazapp is one system with three parts:

1. MT5 Expert Advisors:
   - Mapazapp_BridgeEA: exports real MT5 data in the future.
   - Mapazapp_IFVG_TestEA: used later for MT5 Strategy Tester backtesting.

2. Local external app:
   - future Python/backend + SQLite.
   - imports BridgeEA data.
   - imports backtest results.
   - handles Risk Guard, Prop Firm Guard, Journal and live scanner.

3. Dashboard:
   - React/web UI.
   - This is the only part you must build now as a mock.
